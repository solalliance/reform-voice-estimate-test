# リフォーム見積もり・音声対話テスト

DB / MCPなしで音声→聞き返し→見積もり下書きまでを検証するページです。
GitHub Pagesは `public/` のみ公開。音声API接続は `server.mjs` を別のNode.jsホストで起動します。

## ローカルで音声を試す（Node.js 22以降）

1. `.env.example` を `.env` にコピー。
2. 自分のOpenAIプロジェクトの `OPENAI_API_KEY` と、ランダムな `DEMO_ACCESS_CODE` を設定。
3. `npm start` → http://localhost:8787 を開く。
4. 「接続設定」にテスト用接続コードを入力。「会話を始める」を押してマイクを許可。

通常のAPIキーはサーバー環境変数にだけ設定します。GitHub / Pages / ブラウザ / チャットには貼り付けません。

## GitHub Pagesからスマホで試す

1. `server.mjs` をNode.js対応のHTTPSホストに配置。`public/`, `session.mjs` も同じ構成で配置。
2. ホストの環境変数に上記キー・接続コードを設定。`ALLOWED_ORIGIN=https://solalliance.github.io`。
3. 公開ページの「接続設定」に `https://ホスト名/session` と接続コードを入力。
4. HTTPS対応のマイク付きブラウザで使用。接続コードはメモリ上だけに保持。

API利用料とホスト利用料は別途発生。キー未設定時は503で接続を拒否します。
接続コード必須・毎分6接続まで・画面では5分で自動終了。5分制限はクライアント側であり本番の課金上限にはなりません。
本番は個人認証、サーバー側の接続時間制限・利用量管理が必要です。

## テスト例

「山田様邸の洗面台を1台交換。古いものも処分して、床は4㎡張り替え。壁の広さは明日確認」

架空税別単価：洗面台85,000円、撤去12,000円、床4,500円/㎡、壁1,800円/㎡。
確定分は税別115,000円、税込126,500円。壁は未確定で合計に含めません。
途中で「床は5㎡に変更」と訂正し、下書きが更新されることを確認します。
単価表外は要確認とし、勝手に金額を作りません。正式な見積・送付・発注機能はありません。

## 検証

`npm test`：税込計算、未確認項目の除外、不正値の拒否。
実APIの音声往復は、キー・利用枠設定後に実施してください。
`session.mjs` に会話指示文と単価表連携設定があります。

公式仕様：https://developers.openai.com/api/docs/guides/voice-webrtc
